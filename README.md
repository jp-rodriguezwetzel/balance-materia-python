# Balance de materia en Python

## Descripción

Este programa calcula la acumulación de masa en un sistema utilizando la ecuación general de balance de materia.

El usuario introduce los valores de:

- Flujo de entrada
- Flujo de salida
- Generación
- Consumo

El programa calcula automáticamente la acumulación del sistema.

## Tecnologías usadas

- Python
- Visual Studio Code

## Ejemplo de uso

Entrada:
100 kg/h  
80 kg/h  
0 kg/h  
5 kg/h  

Resultado:
La acumulación es: 15 kg/h
